# Recon: ASUS Chromebook CM14 (CM1406CM4A - Dotation Île-de-France 2026)

Reconnaissance notes for the ASUS Chromebook CM14 (model CM1406CM4A) under Developer Mode.

## Identity

- ChromeOS board: `corsola`, board variant `quigon` (`google,quigon`).
- SoC: MediaTek Kompanio 540 (MT8186 / MT8189), 8 cores (2× Cortex-A78 up to 2.6 GHz + 6× Cortex-A55 @ 2.0 GHz), ARM64.
- 8 GB RAM, 128 GB eMMC 5.1 internal storage (`/dev/mmcblk0`).
- Display: 14" Full HD (1920×1080@60Hz) eDP panel.
- Battery: 42Wh / 50Wh extended battery (up to 20h autonomy).

## Kernel & Storage Layout

- Kernel partitions on internal eMMC (`/dev/mmcblk0`):
  - `mmcblk0p2`: KERN-A (ChromeOS production kernel, 32MB)
  - `mmcblk0p3`: ROOT-A (ChromeOS rootfs)
  - `mmcblk0p4`: KERN-B (Omarchy custom/mainline kernel)
  - `mmcblk0p7`: ROOT-C (Omarchy Arch Linux ARM rootfs)
- Depthcharge uses slot-relative root: `root=PARTUUID=%U/PARTNROFF=1` (USB) or `PARTNROFF=3` (internal KERN-B -> ROOT-C).

## Developer-mode flags

`dev_boot_usb=1`, `mainfw_type=developer`. Developer keys are located at `/usr/share/vboot/devkeys/` (`kernel.keyblock`, `kernel_data_key.vbprivk`).
Signing with `vbutil_kernel` enables direct boot via `[Ctrl] + [U]`.
